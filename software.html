Browser-based serial communication and Modbus utilities. No installation required -- just open and use.

Serial Auto Responderv2

Configure trigger/response byte sequences to automatically reply when matching data is received from a serial port. Ideal for protocol simulation and device testing.

  • Web Serial API -- works in Chrome/Edge without drivers
  • Flexible hex input: spaces, commas, or 0x prefix
  • Priority-based rule matching with enable/disable toggle
  • Real-time HEX / ASCII / dual-mode log viewer
  • Import and export rule configurations as JSON

CRC16 Modbus Calculator

Calculate CRC16 checksums for Modbus RTU frames. Enter hex bytes and instantly get the CRC result, CRC low/high bytes, and the complete frame with checksum appended.

  • Standard Modbus CRC16 (polynomial 0xA001)
  • Supports arbitrary hex byte input
  • Displays CRC-Lo and CRC-Hi separately
  • One-click copy of the full frame

Water Level Simulator

Simulate a Modbus RTU water level gauge slave device. Responds to register read requests with configurable water level, temperature, and device parameters.

  • Acts as a Modbus RTU slave via Web Serial API
  • Configurable slave address, baud rate, and register values
  • Real-time request/response monitoring
  • Useful for testing Modbus master implementations
